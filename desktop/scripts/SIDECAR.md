# Sidecar argv + env contract — Farhad Flow CI desktop (Wave 2)

Staff Tauri shell spawns the frozen Python sidecar. **Do not** use system Python.

## Canonical argv

```text
{resources/python}/bin/python3 -m langflow run \
  --host 127.0.0.1 \
  --port {port} \
  --frontend-path {resources/frontend}
```

Windows:

```text
{resources}\python\python.exe -m langflow run `
  --host 127.0.0.1 `
  --port {port} `
  --frontend-path {resources}\frontend
```

| Token | Meaning |
|-------|---------|
| `{resources/python}/…/python` | python-build-standalone from `fetch-python-standalone` |
| `-m langflow` | Relocatable entry — **avoid** absolute shebang scripts under `venv/bin` |
| `--host 127.0.0.1` | Loopback only |
| `--port {port}` | Chosen by shell in **7860–7870** (first free) |
| `--frontend-path {resources/frontend}` | Output of `bake-frontend.sh` |

Helpers generated by freeze:

- Linux: `resources/run-langflow.sh run --host … --port … --frontend-path …`
- Windows: `resources/run-langflow.ps1 run --host … --port … --frontend-path …`

## Env defaults merge

1. Load `resources/env/default.env` (key=value, `#` comments).
2. Shell may override `LANGFLOW_HOST` / `LANGFLOW_PORT` after port scan.
3. **Do not** set secrets in `default.env`.

Shipped defaults (`default.env`):

```text
LANGFLOW_AUTO_LOGIN=true
LANGFLOW_GIT_ENABLED=true
LANGFLOW_GIT_AUTO_COMMIT=false
LANGFLOW_SAVE_DB_IN_CONFIG_DIR=true
LANGFLOW_HOST=127.0.0.1
LANGFLOW_PORT=7860
DO_NOT_TRACK=true
LANGFLOW_TELEMETRY_WRITER_ENABLED=false
LANGFLOW_SKIP_EXTENSION_COMPONENTS=true
LANGFLOW_CREATE_STARTER_PROJECTS=false
LANGFLOW_UPDATE_STARTER_PROJECTS=false
LANGFLOW_LAZY_LOAD_COMPONENTS=true
LANGFLOW_AGENTIC_EXPERIENCE=false
ENABLE_LANGFLOW_STORE=false
```

Shell also **forces** at spawn:
- `LANGFLOW_GIT_AUTO_COMMIT=false` (manual History commit only)
- `LANGFLOW_UPDATE_STARTER_PROJECTS=false` (never wipe/rebuild starters each boot)
- `LANGFLOW_SAVE_DB_IN_CONFIG_DIR=true` (SQLite under config_dir; install tree is read-only)
- `LANGFLOW_CONFIG_DIR` to the resolved user config path

Store / cloud marketplace: **not** enabled via env. FE flag `ENABLE_LANGFLOW_STORE=false` + no `LANGFLOW_STORE_URL` in `default.env` (see [`../BRANDING.md`](../BRANDING.md) Wave 5 §50).

### `LANGFLOW_GIT_FLOWS_DIR`

**Unset by default.** When unset, runtime uses `{config_dir}/flows-repo` (wizard clone/init). Do **not** bake a flows path into the installer.

Optional: `LANGFLOW_CONFIG_DIR` overrides platformdirs config root.

## PATH / library notes

### Windows (DLL search)

Before spawn, prepend to **process** `PATH`:

1. `{resources}\python` (includes vendored `msvcp140*.dll` / `vcruntime140*.dll` from `vendor-msvc-runtime.ps1`)
2. `{resources}\python\DLLs` (if present)
3. `{resources}\venv\Scripts`
4. `{resources}\venv\Lib\site-packages\pywin32_system32` (+ `win32`)
5. `{resources}\venv\Lib\site-packages\onnxruntime\capi` (magika / markitdown)
6. bundled git (`cmd`, `usr\bin`, `mingw64\bin`)

Native wheels (`.pyd`) and `python3XX.dll` resolve via DLL search order. Missing these → import failures on numpy/onnxruntime/etc. Do **not** rely on a system VC++ redistributable for staff installs.

**onnxruntime / markitdown:** Some dev PCs ship an older `onnxruntime.dll` in `System32` or on `PATH`. The sidecar boot script (`resources/_langflow_boot.py`) preloads the bundled `onnxruntime.dll` from `venv/.../onnxruntime/capi` before Langflow imports so magika/markitdown and custom components that pull them in keep working.

### Linux (`LD_LIBRARY_PATH` / RPATH)

Standalone CPython usually embeds RPATH. After relocate, still set:

```bash
export LD_LIBRARY_PATH="{resources/python}/lib${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
```

manylinux wheels that `dlopen` sibling `.so` need this. Smoke imports: `langflow`, `git` (GitPython), `httpx`.

Portable git (`resources/git`) — Wave 3 done. Sidecar-only PATH / `GIT_EXEC_PATH`: see [`git-env.md`](git-env.md) and [`sidecar-git-env.env.example`](sidecar-git-env.env.example). Shell prepends bundled git before spawn; system git optional.

## Integrity

`resources/MANIFEST.sha256` lists sha256 of critical files (python binary, frontend `index.html`, `env/default.env`, launchers, …). Wave 4 boot should verify before spawn.

## Build order (CI)

```bash
# Linux runner (full payload)
./desktop/scripts/fetch-python-standalone.sh linux
./desktop/scripts/bake-frontend.sh          # or SKIP_NPM_BUILD=1 if FE already built
./desktop/scripts/freeze-venv.sh            # full uv sync — needs disk + PyPI
# optional Wave 3:
# ./desktop/scripts/vendor-git.sh
./desktop/scripts/write-manifest.sh         # freeze already writes MANIFEST; re-run OK

# Orchestrator:
./desktop/scripts/build-payload-linux.sh
```

```powershell
# Windows runner
.\desktop\scripts\fetch-python-standalone.ps1 -Target windows
.\desktop\scripts\bake-frontend.sh   # via Git Bash, or pre-bake FE artifact
.\desktop\scripts\freeze-venv.ps1    # ends with verify-payload-windows.ps1
.\desktop\scripts\build-payload-windows.ps1   # verify again before NSIS
```

**NSIS gate (`verify-payload-windows.ps1`)** — fails the build if startup/DLL patches are missing:

| Check | What |
|-------|------|
| `env/default.env` | `SKIP_EXTENSION`, `CREATE/UPDATE_STARTER=false`, `LAZY_LOAD`, `AGENTIC_EXPERIENCE=false` |
| `_langflow_boot.py` | onnxruntime `ctypes.CDLL` preload (UTF-8, no BOM) |
| `python/msvcp140.dll` | vendored MSVC runtime |
| frozen `lfx/interface/components.py` | extension skip + lazy-load base-path guard |
| import smoke | markitdown + onnxruntime under inherited PATH (full freeze only) |

`freeze-venv.ps1` copies workspace `src/lfx/.../components.py` into site-packages after `uv sync`. Rust spawn forces (`UPDATE_STARTER=false`, `SKIP_EXTENSION=true`) ship in `FarhadFlowCI.exe` from `sidecar.rs`.

Staff/CI full freeze (exact):

```bash
cd "$REPO_ROOT"
./desktop/scripts/build-payload-linux.sh
# Windows: .\desktop\scripts\build-payload-windows.ps1
```

Light smoke (structure + FE + python + tiny venv — not shippable):

```bash
./desktop/scripts/fetch-python-standalone.sh linux
SKIP_NPM_BUILD=1 ./desktop/scripts/bake-frontend.sh
SMOKE_ONLY=1 ./desktop/scripts/freeze-venv.sh
```

If `uv sync` times out on PyPI, re-run `./desktop/scripts/freeze-venv.sh` (uv cache reuses downloads).
